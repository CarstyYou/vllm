# task_09 — CuTe MXFP8-K32 MoE GEMM kernel benchmark（RTX PRO 5000 / 5kp）

**主对比：CuTe（FlashInfer sm120 MXFP8 grouped GEMM）vs DeepGEMM 2.5.0+a6b593d（= vLLM vendored 版本）**，同 recipe（GranK=32/UE8M0），BF16（cuBLAS torch.bmm）仅附加参考。kernel 层非 serving。数据全部来自 [benchmark.csv](benchmark.csv)（每 case 独立 3 轮，下表取 3 轮 median）；硬件/版本见 [run_meta.txt](run_meta.txt)。

## 结论

- **CuTe 全面快于 DeepGEMM**：三模型 × G1/G2 × m_pe 全部 case，CuTe/DG 加速 **1.07×–1.31×**（同 MXFP8-K32 recipe）。
- **优势在小 M 最大**：m_pe=128 时约 1.2–1.3×，随 m_pe 增大收敛到 ~1.07–1.12×（大 M 两者都接近 compute ceiling）。
- **kernel 效率**：CuTe 大 m_pe MFU 达 **~85–86%**（占 measured FP8 QMMA ceiling 442.8 TFLOPS），DeepGEMM ~73–78%。
- **correctness**：CuTe calc_diff ~1e-6、DG ~7e-4，均 < 0.002。
